Cara mendapatkan akses admin
  1. Buka GitHub → Settings akun → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Buat token dengan masa berlaku yang Anda tentukan. Pilih akun Hiijee220 dan Only select repositories → Menu_Lyme_Coffe.
  3. Pada Repository permissions, berikan Contents: Read and write. Metadata memakai akses baca bawaan.
  4. Salin token ke kolom di atas. Jangan masukkan token ke kode atau mengirimkannya lewat chat.

Hanya token yang memiliki izin menulis repository ini yang dapat menyimpan perubahan. Token tidak disimpan di repository maupun penyimpanan browser.
